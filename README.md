# Loan Approval Analysis – Tableau Dashboard

## 📊 Project Overview

This project analyzes loan application data using *Tableau* to understand application volume, approval performance, applicant characteristics, and important factors associated with loan approval.

The project includes an interactive Tableau dashboard containing key performance indicators and visualizations for analyzing loan approval patterns.

## 🎯 Objectives

* Analyze the total number of loan applications.
* Identify the total number of approved applications.
* Calculate the overall approval rate.
* Analyze the average credit score of applicants.
* Compare approval rates across different genders.
* Compare approval rates across different regions.
* Analyze approval rates based on education level.
* Analyze monthly approval-rate trends.
* Analyze the selection rate ratio.

## 📈 Dashboard Components

The dashboard contains the following visualizations:

1. Total Applications
2. Total Approved Applications
3. Overall Approval Rate
4. Average Credit Score
5. Approval Rate by Gender
6. Approval Rate by Region
7. Approval Rate by Education
8. Monthly Approval Rate
9. Selection Rate Ratio

## 🛠️ Tools & Technologies

* Tableau
* Microsoft Excel / CSV Dataset
* python
*github

## 🔍 Key Analysis

The dashboard provides a consolidated view of loan approval performance and allows users to identify differences in approval rates across demographic and geographic categories.

It also provides a monthly trend analysis that can help identify changes in approval performance over time.

## 📌 Conclusion

The Tableau dashboard makes it easier to understand loan approval patterns through interactive visualizations and key performance indicators. The analysis can help identify important differences in approval rates across gender, region, and education levels while providing an overall view of application and approval performance.

The dashboard can be further enhanced by adding filters, advanced calculated fields, predictive analysis, and additional applicant-level insights.
